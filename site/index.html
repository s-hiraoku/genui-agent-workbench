GenUI Popup Broker

AI が作った画面を、
あなたの Mac で
すぐ表示する。

AI（agent）は自分でウィンドウを開けません。GenUI は AI の代わりに、 あなたの Mac で小さな画面（popup）を表示する常駐アプリです。 AI が「こんな画面を出して」という指示書を作り、それをこのアプリに渡すと、 チェック・確認・進捗共有などの画面が手元にポンと開きます。 アプリ自身が文章を考えたり AI を呼んだりはしません ── 画面の中身を決めるのは AI 側です。

How it works

AI が「画面の指示書」を作り、アプリが表示する

GenUI は AI が結果を「見せる」ための画面です。 チャットアプリではなく、アプリ側で AI を動かすこともありません。 AI が作った指示書（OpenUI Lang という書式）を表示するだけ。 流れはとてもシンプルです。

  1. 書き方を調べる

    AI が CLI から prompt-spec を呼び、「画面の指示書」の書き方ガイドを取得します。

  2. 指示書を作る

    AI が出したい画面を決め、その指示書（OpenUI Lang）を書き出します。

  3. アプリに渡す

    CLI の popup コマンドで指示書をアプリに送ります。アプリが起動していなければ broker の起動を試します。

  4. 画面が開く

    アプリが内容をチェックして保存し、手元に popup（小さな画面）を開きます。

Step 1

ダウンロードして起動する

  1. zip をダウンロード

    上部のダウンロードボタンから genui-popup-broker-macos-arm64.zip を取得します。zip には GenUI Popup Broker.app とコマンドライン用の genui が入っています。

  2. アプリを配置

    zip を展開し、GenUI Popup Broker.app を /Applications に移動します。

  3. 初回起動

    Finder でアプリを右クリックして 開く を選びます。未署名ビルドなので、ダブルクリックでは macOS のセキュリティ警告で止まります。macOS 15 以降ではシステム設定から許可が必要です ── 詳しい手順は困ったときを参照してください。

  4. 常駐を確認

    起動すると、メニューバー右上のトレイに GenUI のアイコンが現れ、ずっと待機します。トレイのメニューから設定ウィンドウが開けば準備完了です。

Step 2

CLI を置いて最初の画面を出す

ダウンロードしたアプリは、画面（popup）を表示する待機役です。 AI からアプリを呼び出すためのコマンド（CLI）も zip に入っているので、 展開したフォルダで以下を実行します。Node.js が入っていない Mac でも、 CLI はインストール済みアプリ内の実行環境を使えます。

OpenUI Lang

画面の指示書はこう書く

「画面の指示書」＝ OpenUI Lang は、用意された部品（コンポーネント）を名前で組み合わせ、 root から全体を組み立てる書式です。AI はこれを書くだけ。 見た目のデザインはこのアプリ側が受け持ちます。

Component library

使える画面パーツ（コンポーネント）

画面は、あらかじめ用意された部品（コンポーネント）を組み合わせて作ります。 AI が使えるのはこの一覧の部品だけ。すべての部品と書き方の例は genui prompt-spec で確認できます。

For agents

AI に渡す最小手順

コマンド（CLI）は AI に向けて自分の使い方を説明します。 現在の developer preview では、共通 checkout の中で npm run genui -- ... を実行します。 公開版ではプロジェクトから直接呼べる genui コマンドに寄せる予定です。

Troubleshooting

詰まりやすいところ

「マルウェアが含まれていないことを検証できませんでした」と出て起動できない

これは macOS のセキュリティ機能（Gatekeeper）による警告で、マルウェアだから出ているわけではありません。 このアプリは Apple Developer ID での署名・公証（notarization）をしていない、個人・ローカル配布向けの未署名ビルドのため必ず表示されます。 お使いの macOS のバージョンに合わせて、次のいずれかで開けます。

方法 1 ── 右クリックで開く（macOS 14 以前）

  1. Finder で /Applications の GenUI Popup Broker.app を右クリック（Control+クリック）します。
  2. メニューから 「開く」 を選びます。
  3. 同じ警告が出ますが、今度は 「開く」 ボタンが押せるので押します。

方法 2 ── システム設定から許可（macOS 15 Sequoia 以降）

  1. 一度アプリをダブルクリックして警告を出し、いったん閉じます。
  2. システム設定 → プライバシーとセキュリティ を開きます。
  3. 下にスクロールすると「"GenUI Popup Broker.app" はブロックされました」と表示され、横に 「このまま開く」 ボタンがあります。クリックして Touch ID かパスワードで認証します。

方法 3 ── ターミナルで検疫フラグを外す（確実）

ダウンロード時に付く検疫属性を外すと、通常どおり開けるようになります。

xattr -dr com.apple.quarantine "/Applications/GenUI Popup Broker.app"
コマンドがアプリに接続できない

まずアプリを起動してください。genui popup は未起動時に自動でアプリを立ち上げますが、状態は genui status で確認できます。通信は 127.0.0.1（あなたの Mac の中だけ）に限定され、外部には公開されません。

genui が見つからない

zip に同梱されている genui を ~/.local/bin など PATH の通った場所にコピーしてください。PATH が未設定なら、ターミナルの設定ファイルで export PATH="$HOME/.local/bin:$PATH" を追加します。

「こういう画面を出して」と文章で頼める？

いいえ。アプリ自身は文章を読み取ったり AI を呼んだりしません。どんな画面にするかは AI 側が決め、その指示書（OpenUI Lang）をコマンドでアプリに渡します。

popup が表示されない

genui validate --openui-lang-file ui.openui を実行し、OpenUI Lang の検証エラーを先に解消します。検証を通った OpenUI Lang だけがアーティファクトとして保存・描画されます。

公開配布に使えるか

社内・個人配布なら zip で運用できます。外部向けには Developer ID 署名と notarization を追加してください。
