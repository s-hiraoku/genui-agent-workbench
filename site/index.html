Agent UI for local work

AI agent が作った UI を、ローカル popup としてすぐ表示する。

GenUI Popup Broker は macOS に常駐するローカルアプリです。 agent は OpenUI Lang を CLI で渡すだけで、確認・判断・進捗共有用の popup を開けます。

macOS arm64 をダウンロード Release を開く

GitHub Pages 上で開くと、このボタンは最新 Release の zip に自動でつながります。

必要なもの

アプリ
macOS Apple Silicon
CLI
Node.js 24 + Git
配布 asset
genui-popup-broker-macos-arm64.zip

Step 1

ダウンロードして起動する

  1. zip をダウンロード

    このページ上部のダウンロードボタンから genui-popup-broker-macos-arm64.zip を取得します。

  2. アプリを配置

    zip を展開し、GenUI Popup Broker.app を /Applications に移動します。

  3. 初回起動

    Finder でアプリを右クリックして 開く を選びます。未署名ビルドなので、通常のダブルクリックでは Gatekeeper が止める場合があります。

  4. 常駐確認

    起動後、メニューバーに GenUI Popup Broker が常駐します。設定画面が開ければ準備完了です。

Step 2

CLI を準備して初回 popup を出す

ダウンロードしたアプリは popup を開く resident broker です。 agent から呼ぶ CLI はこのリポジトリに含まれるので、開発用 shell で以下を実行します。

Agent workflow

agent に渡す最小手順

1. 仕様を読む

npm run genui -- prompt-spec
npm run genui -- components

2. OpenUI Lang を生成

自然言語プロンプトを broker に渡さず、agent が OpenUI Lang を生成します。

3. validate して popup

開く前に必ず validate を通し、失敗したら OpenUI Lang を修正します。

Troubleshooting

詰まりやすいところ

macOS が「開発元を確認できない」と表示する

未署名 zip のためです。Finder でアプリを右クリックして 開く を選ぶか、システム設定の「プライバシーとセキュリティ」から許可します。

CLI が broker に接続できない

まずアプリを起動してください。その後、npm run genui -- status で resident broker の状態を確認します。

npm run genui が見つからない

CLI はアプリ zip ではなく、この GitHub リポジトリ側にあります。git clone して npm ci を実行したディレクトリでコマンドを実行してください。

popup が表示されない

npm run genui -- validate --openui-lang-file ui.openui を実行し、OpenUI Lang の validation error を先に解消します。

公開配布に使えるか

社内・個人配布なら zip で運用できます。外部向けには Developer ID 署名、notarization、アプリアイコン設定を追加してください。
