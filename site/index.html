GenUI Popup Broker

AI agent のための、
常駐型ローカル UI
ブローカー。

agent が自分でウィンドウを持たなくても、リッチな一時 UI を表示できます。 agent が OpenUI Lang を生成し、CLI が常駐する Electron ブローカーに送信。 ブローカーが検証・保存し、popup として描画します。 チャットアプリでも、ブローカー側 LLM でもありません ── UI の設計は呼び出し側の agent が担います。

How it works

agent → OpenUI Lang → popup

GenUI は agent の視覚的な出力面です。 自然言語プロンプトをブローカーに渡したり、ブローカー側で LLM を呼んだりはしません。 次の一方向フローで動きます。

  1. 仕様を読む

    agent が genui prompt-spec で OpenUI Lang のオーサリングガイドを取得します。

  2. UI を生成

    agent が表示したい UI を決め、OpenUI Lang を生成します。

  3. CLI で送信

    genui popup が常駐ブローカーに接続。未起動なら自動で立ち上げます。

  4. 検証して描画

    ブローカーが検証し、.genui/artifacts に保存して popup を開きます。

Step 1

ダウンロードして起動する

  1. zip をダウンロード

    上部のダウンロードボタンから genui-popup-broker-macos-arm64.zip を取得します。これは npm run electron:pack で作られる未署名ローカルパッケージです。

  2. アプリを配置

    zip を展開し、GenUI Popup Broker.app を /Applications に移動します。

  3. 初回起動

    Finder でアプリを右クリックして 開く を選びます。未署名ビルドなので、通常のダブルクリックでは Gatekeeper が止める場合があります。

  4. 常駐を確認

    起動後、トレイに GenUI Popup Broker が常駐します。トレイのメニューから設定ウィンドウが開けば準備完了です。

Step 2

CLI を準備して最初の popup を出す

ダウンロードしたアプリは popup を開く常駐ブローカーです。 agent から呼ぶ CLI はこのリポジトリに含まれるので、開発用 shell で以下を実行します。

OpenUI Lang

UI は宣言的に組み立てる

OpenUI Lang は、用意されたコンポーネントを変数として束ね、root から構成する宣言的な記法です。 agent はこれを生成するだけで、スタイリングはこのリポジトリ側が所有します。

Troubleshooting

詰まりやすいところ

macOS が「開発元を確認できない」と表示する

未署名 zip のためです。Finder でアプリを右クリックして 開く を選ぶか、システム設定の「プライバシーとセキュリティ」から許可します。

CLI がブローカーに接続できない

まずアプリを起動してください。genui popup は未起動時に自動でブローカーを立ち上げますが、状態は npm run genui -- status で確認できます。API は 127.0.0.1 のローカル限定で、トークンは .genui/broker.json に書き出され CLI が自動付与します。

npm run genui が見つからない

CLI はアプリ zip ではなく、この GitHub リポジトリ側にあります。git clone して npm install を実行したディレクトリでコマンドを実行してください。

自然言語の指示を popup にできる？

いいえ。ブローカーは自然言語プロンプトを解釈せず、LLM も呼びません。UI の設計は呼び出し側の agent が行い、生成した OpenUI Lang を CLI で渡します。

popup が表示されない

npm run genui -- validate --openui-lang-file ui.openui を実行し、OpenUI Lang の検証エラーを先に解消します。検証を通った OpenUI Lang だけがアーティファクトとして保存・描画されます。

公開配布に使えるか

社内・個人配布なら zip で運用できます。外部向けには Developer ID 署名と notarization を追加してください。
